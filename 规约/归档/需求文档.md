## 1. 项目定位

基于 100ask i.MX6ULL Pro（Cortex-A7 单核 / 512MB / 1024×600 触摸屏）的**多用户共享保险柜系统**，面向民宿/短租、小型办公室、多成员家庭等「多人共用同一柜体」场景。

核心认证链路为 **FM225 双目人脸识别 + TOTP 动态密码双因子**，配套 LVGL 本地界面、MQTT 远程监控与 RPC 远程指令，以及**限时/限次的临时授权**（房客退房自动失效）。系统**离线运行**，认证不依赖外网；局域网内可通过 MQTT 客户端查看状态、下发开锁与管理指令。

## 2. 角色模型与认证

| 角色 | 说明 | 关键权限 |
|---|---|---|
| 管理员（admin） | 柜体 owner / 运维 | 用户增删改、策略调整、设置中枢二次验证、远程开锁 |
| 长期用户（user） | 家庭成员 / 员工 | 人脸+PIN/OTP 正常开锁 |
| 临时用户（temp） | 房客 / 访客 | 限时限次开锁，到期/用量耗尽自动失效（FR-9） |

- 认证方式：纯数字 **PIN（4–8 位）**；`auth_method` 字段预留 `"otp"`（后续接手机动态码）。
- 人脸置信度三档策略（默认 `score_high=85`，`score_mid=60`）：
  - ≥ `score_high` → 直接 UNLOCK；
  - ≥ `score_mid` → WAIT_OTP（进入动态码二次确认态）；
  - 否则 → DENY。
- **敏感操作二次确认细化（2026-08-31）**：**仅当修改「管理员」密码时**，保存前强制弹动态码（TOTP）键盘校验（`backend_admin_verify_totp`）；普通用户改密不要求动态码，仅校验旧 PIN。删除用户仍走管理员 PIN 二次验证。

## 4. 非功能需求

- **离线优先**：认证链路不依赖外网；远程通道仅限局域网。
- **安全**：PIN 仅存哈希（每用户随机盐）；连续失败锁定；敏感操作二次验证；审计可追溯。
- **性能**：目标单核 A7，UI 帧率满足交互；开锁脉冲硬上限受硬件约束（执行器高脉冲 ≤500ms）。
- **可测试**：支持 headless（Xvfb + SDL + mosquitto）MQTT 验收，状态机可脚本化断言。
- **可移植**：HAL 后端注册机制，同一份 `app/` 源码可在 PC（SDL）与板子（FBDEV）双平台构建。
- **主题一致性**：全部 UI 控件通过 `theme_color()` / 全局 `lv_style_t` 取色，禁止硬编码 hex；换主题无需重建页面。**默认主题为「月白」（浅色暖色，index 1）**。
