# 迁移清单（旧结构 → 新结构）

旧实现整体冻结到 `legacy/`，不参与构建，仅作迁移对照。
每迁完一个模块在下表打勾，并跑一次 PC 构建。

## 1. 路径映射

| 旧路径 | 新路径 | 改动要点 |
|---|---|---|
| `src/main.c` | `app/main.c` + `app/app.c` + `app/platform/*` | 拆成进程入口、应用编排、平台引导三块 |
| `src/lib/*` | `ports/lv_port/*` | 仅移动，内容不变 |
| `src/core/config.c/h` | `app/core/config.c/h` | 语义改名：系统配置（阈值/MQTT/日志保留）；旧密码文件逻辑并入 store |
| `src/core/store.c/h` | `app/core/store/*` | 拆成门面 + user/log/net 三个仓库 |
| `src/core/unlock_backend.c/h` | `app/core/auth/unlock_backend.c/h` | 返回值改用 `auth_result_t`（不变），内部错误码统一 |
| `src/core/auth_fsm.c/h` | `app/core/auth/auth_fsm.c/h` | 人脸数据改从人脸服务事件获取 |
| `src/core/totp.c/h` | `app/core/auth/totp.c/h` | 不变 |
| `src/core/rpc.c/h` | `app/core/remote/rpc.c/h` | 事件上报改走事件总线 |
| `src/core/mqtt_client.c/h` | `app/core/remote/mqtt_client.c/h` | 加特性开关，关闭时替换为存根 |
| `src/core/worker.c/h` | `app/core/support/worker.c/h` | 不变 |
| `src/core/async_store.c/h` | `app/core/support/async_store.c/h` | 不变 |
| `src/core/crypto.c/h`、`sha1.c/h` | `app/core/support/crypto.c/h`、`sha1.c/h` | 不变 |
| `src/hal/actuator.c/h` | `app/hal/actuator/*` + `app/hal/hal_actuator.h` | 接口换成 `hal_actuator_*`，脉冲上限不变 |
| `src/hal/hal_time.c/h` | `app/hal/time/*` + `app/hal/hal_time.h` | 返回值加错误码 |
| `src/hal/hal_face.c/h` | `app/hal/face/*` + `app/hal/hal_face.h` | 同步 poll 改异步事件 + 后端注册 |
| `src/ui/*` | `app/ui/*` | 仅改 include 路径，行为不变 |
| `src/safe/*` | `data/*` | 运行时数据搬出源码树 |
| `tools/*` | `tools/*` | 不变 |

## 2. 接口变更对照

| 旧接口 | 新接口 | 兼容做法 |
|---|---|---|
| `hal_face_poll(face_result_t *)` | `face_service_subscribe()` + `FACE_EV_DETECT` | 保留一个 `face_service_poll()` 兼容包装，内部从事件队列取，迁移期两种都能用 |
| `hal_face_init()` | `face_service_init(const char *backend)` | 旧名保留为宏，指向默认后端 |
| `hal_face_inject()` | `face_service_inject()` | 同上 |
| `actuator_init()` / `actuator_drive()` | `hal_actuator_init()` / `hal_actuator_pulse()` | 旧名保留为静态内联包装 |
| `hal_time()` | `hal_time()` | 签名不变，加 `hal_time_source()` |
| `auth_fsm_set_ui_hook()` / `set_event_cb()` | `event_bus_subscribe(EV_AUTH_STATE / EV_AUTH_RESULT)` | 旧接口保留为薄封装，内部转发到总线 |
| `rpc_set_event_hook()` | `event_bus_subscribe(EV_AUTH_RESULT)` | 同上 |
| `theme_register_change_cb()` | `event_bus_subscribe(EV_THEME_CHANGED)` | 同上 |

旧接口保留一个迁移周期，待全部调用点改完后统一删除（清单见第 4 节）。

## 3. 迁移状态

| 模块 | 状态 | 验证方式 |
|---|---|---|
| 目录骨架与构建 | 待迁移 | PC 构建通过 |
| `core/support`（worker、crypto、sha1、async_store） | 待迁移 | 单测 + 构建 |
| `core/err.h`、`core/event_bus` | 新增 | 构建 |
| `core/store` | 待迁移 | 单测 + 界面读写 |

| `core/remote`（mqtt、rpc） | 待迁移 | MQTTX 联调 |
| `hal/face` | 新设计 | 注入分数验证状态机 |
| `hal/time`、`hal/actuator`、`hal/camera` | 待迁移 | 构建 |
| `platform`（SDL/FBDEV 引导） | 待迁移 | PC 运行 + 板子配置 |
| `ui` | 待迁移 | PC 运行逐页比对 |
| `tests` | 新增 | `ctest` |

## 4. 旧接口删除计划

新结构跑通并完成 PC 验收后，删除以下兼容层：

1. `face_service_poll()` 与 `hal_face_*` 旧名宏；
2. `auth_fsm_set_ui_hook()` / `auth_fsm_set_event_cb()` / `rpc_set_event_hook()`；
3. `actuator_*` 旧名包装；
4. `legacy/` 整个目录（确认无引用后）。

## 5. 回退方式

`legacy/` 冻结了迁移前的完整实现，且 git 有提交历史。
任何一步迁移出问题，删掉新目录重新配置构建即可回到旧状态：
旧构建目录 `build_pc` 在迁移开始前已可编译，接口兼容层保证中途不会卡死。
