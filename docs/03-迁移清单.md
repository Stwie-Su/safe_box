# 迁移清单（重构实施计划）

| 项目 | 内容 |
|---|---|
| 上级文档 | `docs/01-需求规格.md`、`docs/02-架构设计.md` |
| 迁移策略 | 新骨架先行，旧实现逐个迁入；旧代码冻结在 `legacy/`，git 分支 `refactor/skeleton` |
| 回退方式 | 切回原分支即可；`legacy/` 保留整个旧树，迁移完成前不删 |

## 1. 目录映射

| 旧路径 | 新路径 | 说明 |
|---|---|---|
| `src/lib/` | `ports/lv_port/` | LVGL 官方 Linux 移植层，与业务代码彻底分开 |
| `src/main.c` | `app/main.c` + `app/app.c` + `app/platform/` | 进程入口只留引导，平台差异进 platform |
| `src/core/store.c/h` | `app/core/store/store.c/h` | 存储门面，对外函数签名保持不变 |
| `src/core/config.c/h` | `app/core/store/credentials.c/h` | 旧 config 实际管的是开锁密码，改名避免与系统配置混淆 |
| `src/core/auth_fsm.c/h` | `app/core/auth/auth_fsm.c/h` | 认证域归堆 |
| `src/core/totp.c/h` | `app/core/auth/totp.c/h` | 同上 |
| `src/core/unlock_backend.c/h` | `app/core/auth/unlock_backend.c/h` | 同上 |
| `src/core/worker.c/h` | `app/core/support/worker.c/h` | 基础设施归堆 |
| `src/core/async_store.c/h` | `app/core/support/async_store.c/h` | 同上 |
| `src/core/crypto.c/h`、`sha1.c/h` | `app/core/support/` | 同上 |
| `src/core/rpc.c/h`、`mqtt_client.c/h` | `app/core/remote/` | 远程通道，可整体裁剪 |
| `src/hal/hal_face.c/h` | `app/hal/face/` | 重写为异步服务 + 可注册后端 |
| `src/hal/hal_time.c/h` | `app/hal/time/` | 门面 + 系统时间后端，RTC 后端留位 |
| `src/hal/actuator.c/h` | `app/hal/actuator/` | 门面 + 模拟后端，GPIO 后端留位 |
| — | `app/hal/camera/` | 新增，FR-7 视频预览接口预留 |
| `src/ui/*` | `app/ui/*` | 结构不变，只调整 include |
| `src/safe/` | `data/` | 运行时数据移出源码树，不入库 |

## 2. 接口变更

| 旧接口 | 新接口 | 迁移方式 |
|---|---|---|
| `actuator_init()` | `hal_actuator_init()` | 调用点改名 |
| `actuator_get_state()` | `hal_actuator_state()` | 调用点改名 |
| `actuator_pulse(ms)` | `hal_actuator_pulse(ms)` | 500ms 上限由实现保证 |
| `hal_face_init/poll/enroll/delete/inject` | `face_service_*` 异步接口 | auth_fsm 改为事件订阅 |
| `config_get_password()` 等 | `credential_*` | 头文件改名，函数签名不变 |
| 数据目录 `src/safe` | `store_dir()` → `SAFE_DATA_DIR` | 编译期宏 + 环境变量 `SAFE_DATA_DIR` |
| `rpc_init("127.0.0.1", 1883)` | 由 `app_config()` 提供 host/port | 配置集中 |

## 3. 新增模块

| 模块 | 作用 |
|---|---|
| `app/core/err.h`、`err.c` | 统一错误码与错误描述 |
| `app/core/event_bus.c/h` | 事件总线，替代散落的回调字段 |
| `app/core/config.c/h` | 系统配置快照（阈值、MQTT、日志保留、数据目录） |
| `app/hal/face/face_service.c` | 人脸服务门面 + 后端注册 |
| `app/hal/face/backend_fake.c` | 模拟后端，注入分数 |
| `app/hal/face/backend_fm225.c` | FM225 协议层占位，待硬件 |
| `app/hal/face/backend_none.c` | 空后端，人脸通道停用时用 |
| `app/platform/platform_sdl.c` | PC 引导：命令行、SDL 后端、窗口 |
| `app/platform/platform_fbdev.c` | 板子引导：FBDEV + EVDEV、防息屏 |
| `app/platform/perf_probe.c` | 性能探针（环境变量开启） |
| `tests/` | CTest 用例 |
