# 测试计划

测试分两层：PC 上的 CTest 单元/集成用例，以及 MQTTX 参与的手动联调。
板子交叉编译时默认关闭测试目标（`SAFE_BUILD_TESTS=OFF`）。

## 1. CTest 用例

用例放在 `tests/`，链接 `safe_core` 静态库，不依赖 LVGL。

### 1.1 置信度分级（`test_auth_fsm`）

| 用例名 | 输入 | 期望 |
|---|---|---|
| `score_59_deny` | 59 | DENY |
| `score_60_wait_otp` | 60 | WAIT_OTP |
| `score_75_wait_otp` | 75 | WAIT_OTP |
| `score_84_wait_otp` | 84 | WAIT_OTP |
| `score_85_unlock` | 85 | UNLOCK |
| `score_100_unlock` | 100 | UNLOCK |
| `score_neg_invalid` | -1 | 状态不迁移 |
| `score_over_invalid` | 101 | 状态不迁移 |
| `score_75_otp_ok` | 75 + 正确 TOTP | UNLOCK |
| `score_75_otp_bad` | 75 + 错误 TOTP | DENY |

### 1.2 TOTP（`test_totp`）

| 用例名 | 输入 | 期望 |
|---|---|---|
| `current_window` | 当前窗口码 | 通过 |
| `prev_window` | 上一个窗口（−30s） | 通过（±1 容忍） |
| `next_window` | 下一个窗口（+30s） | 通过（±1 容忍） |
| `two_window_ago` | 上上个窗口（−60s） | 拒绝 |
| `replay_same_window` | 同一窗口码用第二次 | 拒绝（防重放） |
| `wrong_code` | 错误码 | 拒绝且失败计数 +1 |

### 1.3 失败锁定（`test_lockout`）

| 用例名 | 输入 | 期望 |
|---|---|---|
| `four_fails_ok` | 连续 4 次失败 | 未锁定，可继续 |
| `fifth_fail_lock` | 第 5 次失败 | 进入 LOCKOUT，剩余 30s |
| `try_while_locked` | 锁定期间尝试 | 立即拒绝 |
| `lock_expire` | 倒计时结束 | 回 IDLE，计数清零 |
| `success_reset` | 成功一次后 | 该用户计数清零 |
| `per_user_isolation` | A 用户锁定后 B 用户尝试 | B 不受影响 |

### 1.4 存储（`test_store`）

| 用例名 | 输入 | 期望 |
|---|---|---|
| `user_crud` | 增改删查 | 数据一致，落盘可读 |
| `pin_hash_verify` | 正确/错误 PIN | 校验结果正确 |
| `old_json_defaults` | 缺人脸/动态码字段的旧 JSON | 反序列化给默认值，不丢数据 |
| `log_rotate` | 写入超过保留上限 | 滚动转存，条数回到上限内 |
| `admin_floor` | 删除最后一个启用管理员 | 拒绝，返回错误码 |

## 2. 手动联调（PC + MQTTX）

| # | 操作 | 期望 |
|---|---|---|
| 1 | 发 `query_status` | `safe/log` 收到状态回执 |
| 2 | 注入 score=90 | 直接开锁，`safe/log` 有 UNLOCK |
| 3 | 注入 score=75 | 弹动态密码页，输入正确 TOTP 后开锁 |
| 4 | 注入 score=50 | 直接拒绝，`safe/log` 有 DENY |
| 5 | 连续 5 次失败 | 进入 LOCKOUT，界面倒计时 30s |
| 6 | 订阅 `safe/log` | 事件流完整可见 |
| 7 | 发 `remote_unlock`（不带 otp） | 本地弹动态码页，回执 2001 |
| 8 | 发 `set_face_enable`（不带 otp） | 拒绝，回执 2001 |
| 9 | 断网再恢复 | 自动重连，界面指示灯恢复 |

## 3. 分层检查脚本

`tools/check_layers.sh` 做静态校验，失败则以非零码退出：

1. `app/core` 下不出现 `#include "lvgl.h"`、`lv_*.h`；
2. `app/core` 下不出现 `<linux/`、`SDL2/`、`cJSON.h`、`MQTTClient.h`；
3. `app/hal/*.h` 头文件中不出现平台头文件；
4. `app/ui` 下不出现 `<linux/`、`MQTTClient.h`。

该脚本接入 CTest，作为 `check_layers` 用例。

## 4. 运行方式

```bash
cmake -B build_pc -DLV_PORT_DEFCONFIG=configs/pc.defconfig .
cmake --build build_pc -j$(nproc)
ctest --test-dir build_pc --output-on-failure
```
